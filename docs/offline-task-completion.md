# オフラインの編集経路でも繰り返しの完了を止める

**いつ読むか**: タスクのオフライン編集・完了操作を変更するとき。

一覧の完了切り替えだけでなく、TaskFormの保存も完了状態を書ける。
taskEditは通常の更新として再送され、次回分を作るcompleteTaskを通らない。
そのため、未完了から完了への変更で、元のタスクまたは保存値に繰り返しがある場合は
キューへ積む前に断る（#1250）。新規・仮タスクも同じ判定を通す。
完了済みの編集・未完了への戻し・完了状態を変えない編集は引き続き保存できる。

確認: offline-queue/ops.test.mtsの回帰テスト。画面では通信を切り、繰り返しタスクを
編集して完了にして保存する。入力画面と値が残り、理由が表示されることを確認する。
完了を外せば編集を保存できる。オンラインに戻し未送信の変更を同期したあと、
一覧の完了操作で次回分を作成する。
